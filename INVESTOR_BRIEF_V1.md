# Investor & Research Funding Brief — Neural Thinking Machine / WANGA Architecture

## Purpose

This document presents the current research and funding position of the Neural Thinking Machine (NTM) project and identifies the project as seeking qualified funding, research partners, and scientific collaborators.

## What is being built

The Neural Thinking Machine is the cognitive CPU / Logic Anchor of the WANGA architecture. It is a coordination and reasoning layer above individual AI models rather than a single model itself.

The architectural objective is to coordinate multiple model providers and specialist nodes for quality, reasoning diversity, verification, provenance, and reliable task execution. Model collection is therefore intended primarily to improve the quality and coverage of computation, not simply to increase raw compute capacity.

Core pipeline:

`Priority → Context → Intent → Cognitive Orchestrator → Computation Allocation → Specialist Nodes → Critic/Verifier → Synthesizer → Decision Gate → Neural OS → Execution Gateway → Audit/Provenance`

Current engineering direction includes:

- 28 explicit reasoning/orchestration modes.
- Adaptive inference-time computation allocation.
- Task and result envelopes with provenance and uncertainty fields.
- A machine registry designed to scale to M100+ compute nodes.
- Verification gates and audit recording.
- Replaceable model providers and specialist compute nodes.
- Drift control and recovery-oriented orchestration.
- A multi-model architecture in which different AI systems can contribute specialized computation to a common reasoning pipeline.

The M100+ registry is an architectural scaling target; it should not be interpreted as 100 live model connections already deployed.

## Architecture expansion scenario

A future ×10 architecture scenario would expand the orchestration layer substantially — for example, toward hundreds of reasoning strategies, larger logical node registries, broader model diversity, deeper verification, and more extensive provenance and audit infrastructure.

The objective of this expansion is **quality of computation and coordinated reasoning**, rather than a simple ×10 increase in GPU capacity.
