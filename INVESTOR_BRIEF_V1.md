# Investor Brief — Neural Thinking Machine / WANGA Architecture

## Purpose

This document summarizes the current investor-facing position of the Neural Thinking Machine (NTM) project and the intended use of initial financing.

## What is being built

The Neural Thinking Machine is the cognitive CPU / Logic Anchor of the WANGA architecture. It is a coordination and reasoning layer above individual AI models rather than a single model itself.

Core pipeline:

`Priority → Context → Intent → Cognitive Orchestrator → Computation Allocation → Specialist Nodes → Critic/Verifier → Synthesizer → Decision Gate → Neural OS → Execution Gateway → Audit/Provenance`

The current engineering direction includes:

- 28 explicit reasoning/orchestration modes.
- Adaptive inference-time computation allocation.
- Task and result envelopes with provenance and uncertainty fields.
- A machine registry designed to scale to M100+ compute nodes.
- Verification gates and audit recording.
- Replaceable model providers and specialist compute nodes.
- Drift control and recovery-oriented orchestration.

The M100+ registry is an architectural scaling target; it should not be interpreted as 100 live model connections already deployed.

## Internal valuation framework

For current investor discussions, the working internal estimate is:

- **USD 20–50 million** — current technology architecture as presently defined.
- **USD 50–150 million** — longer-term production-platform scenario including the full orchestration stack, infrastructure, observability, permissions, memory/context systems and a large connected model fleet.

These figures are internal working estimates for discussion. They are not an independent third-party appraisal, audited valuation, or guaranteed transaction price.

## Financing objective

Initial financing is intended to move the project from the current implementation into a funded scientific and engineering program, including:

1. Compute and infrastructure.
2. AI evaluation, reliability and drift-forensics research.
3. Formal verification and reproducibility work.
4. Qualified scientists and technical researchers.
5. Continued development of the Neural OS and orchestration layer.

Any future digital-asset or token mechanism is a separate financing and legal workstream and is not represented here as an already-launched financial product.

## Investor positioning

The investment proposition is the underlying research, software architecture and orchestration technology. The principal objective of the first financing phase is to fund the scientific and engineering team required to turn the architecture into a larger validated platform.

## Current status

The repository contains the operational Thinking Machine specification, Neural OS architecture, task/result schemas, the 28-mode taxonomy, orchestration code, machine registry, planner-agent instructions and automated tests. Further integration of compute nodes, verification, observability and production infrastructure remains part of the roadmap.
