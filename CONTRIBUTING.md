# Contributing

## Before changing code

1. Read `AGENTS.md`.
2. Read `.github/copilot-instructions.md`.
3. Check the relevant architecture and schema documents.
4. Preserve task identity, provenance, verification, and audit semantics.
5. Do not introduce credentials or private data.

## Pull requests

State what changed, why, which contract it affects, what tests were run, and any remaining limitations.

## Claim discipline

Separate implementation facts from research hypotheses and future plans. Do not describe planned machines, integrations, or capabilities as connected unless verified.

## Tests

Run the orchestration test suite before submitting changes. Add deterministic tests for new behavior where practical.
