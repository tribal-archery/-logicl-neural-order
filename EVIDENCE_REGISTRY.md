# Evidence Registry

## Evidence classes

| Class | Establishes |
|---|---|
| ID | Identity |
| ROLE | Organizational role |
| CONTRIBUTION | Actual contribution |
| QUALIFICATION | Stated qualification |
| AUTHORITY | Authorization to act |
| FINANCIAL | Financial or issuance claim from a primary record |
| GOVERNANCE | Appointment or governance decision |
| TECHNICAL | Technical work demonstrated by repository artifacts |

**No evidence → no claim.**

A GitHub account alone does not establish employment, volunteering, qualification, financial authority, investor status, or legal authority.

Each record should contain:

**EVIDENCE_ID → PERSON_OR_ENTITY → CLAIM → CLASS → SOURCE → DATE → HASH (if applicable) → REVIEWER → STATUS → NOTES**
