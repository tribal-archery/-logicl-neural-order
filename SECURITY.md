# Security Policy

## Scope

This repository contains research and engineering code for an AI orchestration architecture.

## Secret handling

Never commit API keys, passwords, access tokens, recovery codes, session cookies, or private credentials.

Use the supported provider authentication mechanism or a secure secret store.

## Reporting

Do not publish credentials or exploit details in a public issue. Use GitHub's private security reporting mechanism when available, or an established private maintainer channel.

This policy describes repository handling expectations; it is not a claim of independent security audit.
