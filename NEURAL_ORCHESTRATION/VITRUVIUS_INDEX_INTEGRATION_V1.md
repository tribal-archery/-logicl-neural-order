## NTM extraction

Vitruvius is useful as a structural indexing model, not as a decorative historical reference.

The Ten Books cover architectural principles, materials, temples and orders, public/private buildings, finishing, water, clocks/astronomy, and machines. The work also contains an explicit index.

Extract the structural pattern:

principles -> elements -> relations -> proportions -> environment -> construction -> mechanisms -> verification
