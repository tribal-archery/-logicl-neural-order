# Agent Registry 1000 V1

## Purpose
Define a 1,000-node logical specialist population around the existing Neural Thinking Machine (NTM), WANGA, AI Drift Forensics, AI²³¹, Ontometric research, scientific workflows, architecture, funding analysis, governance, security, verification, and audit domains.

A logical agent is a role-bearing compute node. It is not automatically a separate account, email address, provider connection, or model.

## Architecture
`Question -> Brain of Brain / Meta Router -> Specialist Population -> Evidence Graph -> Conflict Analysis -> Verification -> Synthesis -> Decision Gate -> Audit`

## Internal composition of every domain
Each 100-node domain contains:
- 20 specialists
- 20 evidence/source analysts
- 20 critics
- 20 cross-domain bridge agents
- 10 measurement/evaluation agents
- 10 domain coordinators

## Agent contract
Every node has: agent_id, domain, role, mission, private_instruction, capabilities, evidence_policy, output_schema, verification_level, status.

Private instructions specialize reasoning but cannot override system rules, authorization, safety, evidence, provenance, or audit requirements.

## Activation tiers
- Focused: 5-20 agents
- Deep: 20-100 agents
- Cross-domain: 100-300 agents
- Full-corpus: up to 1,000 logical agents

The system must not equate more agents with better reasoning. Agent selection is task-aware and evidence-aware.

## Output contract
Each agent returns: `claim + evidence_refs + reasoning_summary + uncertainty + conflicts + dependencies`.

The Brain of Brain preserves materially different observations rather than using majority vote as a truth mechanism.

## Connection states
`planned -> configured -> connected -> verified -> restricted/disabled`

A registry entry is never evidence of a live external connection.

## Security
No API keys, passwords, session tokens, recovery codes, or private credentials belong in this registry.
