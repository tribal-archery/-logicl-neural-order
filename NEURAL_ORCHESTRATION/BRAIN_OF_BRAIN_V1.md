# Brain of Brain V1

## Role
The Brain of Brain is the supervisory control and synthesis layer above the 1,000-agent logical population.

It extends the existing NTM rather than replacing it.

## Control sequence
`Priority -> Context -> Intent -> Project Graph -> Angle Map -> Specialist Routing -> Parallel/Sequential Execution -> Evidence Graph -> Conflict Analysis -> Verification -> Brain of Brain Synthesis -> Decision Gate -> Self-Audit -> Drift Check -> Response`

## Angle Map
An angle is a combination of domain + role + evidence policy + reasoning method + verification depth.

The router selects the smallest sufficient set of angles and expands only when uncertainty, contradiction, or information gaps justify it.

## Evidence Graph
Normalize every observation as: claim, evidence reference, evidence type, source timestamp, agent ID, model/provider ID, uncertainty, reasoning summary, conflict set, dependency set.

## Conflict protocol
1. Compare evidence.
2. Compare scopes.
3. Classify the disagreement as factual, semantic, methodological, or contextual.
4. Dispatch targeted critics/verifiers.
5. Preserve unresolved branches when evidence cannot settle them.

Consensus is not a substitute for evidence.

## Synthesis gate
The final synthesis must distinguish observed fact, sourced claim, model inference, hypothesis, and unresolved question.

A synthesis is accepted only when required evidence, provenance, contradiction handling, authorization, uncertainty, and output-schema checks pass.

## Scaling rule
The 1,000 nodes are a logical population. Runtime activation is task-aware.
