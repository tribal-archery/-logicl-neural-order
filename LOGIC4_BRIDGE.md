# Logic-4 -> 32x28 Bridge

Four letter networks (ב, כ, ל, מ) enter the existing 32-root / 28-node orchestration as typed linguistic events.

## Routing table
| Letter | Branch | Event | Activation |
|---|---|---|---|
| ב | logic4/bet | bet_event | scaffold |
| כ | logic4/kaf | kaf_event | scaffold |
| ל | logic4/lamed | lamed_event | scaffold |
| מ | logic4/mem | mem_event | active target |

## Connection contract
letter network -> validator -> provenance -> 32-root input adapter -> 28-node circular adapter -> canonicalization.

Identity of the letter is preserved across the bridge. A 32-root or 28-node operation may transform the event representation, but it must not silently replace the originating letter.

## Current execution gate
Only מ is enabled for active execution in this phase. ב/כ/ל are registered and structurally connected but disabled.

## Important distinction
Logic-4 here is the project's fourth-order architectural label. It should not be read as a claim that Hebrew grammar itself contains a neural or formal fourth-order logic system.
